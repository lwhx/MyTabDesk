# MyTabDesk

MyTabDesk 是一个本地优先的浏览器标签页工作台扩展，用来保存、整理和恢复浏览器标签页。它通过“空间 - 分组 - 链接”的结构，帮助你把不同任务场景下的网页收纳起来。MyTabDesk 不覆盖浏览器默认新标签页，仅在用户点击扩展图标或通过右键菜单等入口时打开。

## 核心功能

- 三栏标签页工作台
- 空间创建、切换、删除和排序
- 分组创建、折叠、置顶、删除和排序
- 链接展示、打开、编辑、删除和跨分组移动
- 链接备注，备注随工作台数据同步并参与全局搜索
- 链接和分组颜色标记，支持 7 种颜色，搜索栏可用 color:red 按颜色筛选
- 当前空间重复链接扫描，按规范化 URL 保留最新项并为旧项写入同步墓碑
- 当前窗口标签页读取、搜索和保存
- 可将右侧当前标签直接拖入工作台分组
- 自动会话快照、历史恢复和 Chrome 原生标签组恢复
- 会话可恢复到新窗口或当前窗口，并可跳过已经打开的 URL
- 会话详情支持按标签多选、全选或清空，并只恢复选中的标签
- 回收站：删除的空间/分组/链接保留 30 天可恢复，支持撤销删除和永久删除，永久删除写入最小同步墓碑防止跨设备复活
- 链接健康检查：批量检查 URL 是否仍可访问，标记失效、超时和受限链接
- 保存并关闭、保存并休眠
- 浏览器书签目录导入
- `Ctrl/Command + K` 全局命令面板，可搜索所有空间、分组、链接和当前标签
- 使用统计仪表盘：每日保存/恢复趋势、网站停留时间排行、空间健康度，数据仅保存在本机
- 标签页生命周期管理：追踪标签打开时长和闲置状态，保护固定/音频/白名单标签，一键整理闲置标签
- 空间模板：将当前空间保存为模板，之后快速创建相同分组结构的新空间
- HTML 导出：将当前空间导出为带内联样式、可离线分享的独立网页
- 定时保存：每天指定时间自动将当前窗口标签保存到目标空间和分组
- AI 分组建议：只发送链接 ID、标题和域名，预览确认后才调整分组；API Key 仅保存在本机
- 网站图标离线缓存：最多缓存 500 个 favicon，100KB 单图上限，LRU 自动清理，不参与同步或备份
- 统计趋势支持 7/14/30/90 天范围切换，F15 基础统计已统一并入使用统计页
- 浏览器快捷键：`Alt + Shift + D` 打开工作台，`Alt + Shift + S` 保存当前标签
- 深色模式、左栏折叠、右栏折叠
- 批量删除链接
- 完整原生备份导入和导出
- TabTab 兼容导出与导入
- AES-GCM 加密备份导入和导出
- WebDAV / GitHub Gist 手动同步和自动同步
- 右键菜单快速保存页面或链接

## 安装方式

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前项目目录。
5. 将 MyTabDesk 固定到浏览器工具栏，点击浏览器工具栏中的 MyTabDesk 扩展图标即可打开工作台；也可以通过网页右键菜单中的“打开 MyTabDesk”进入。

## 使用说明

1. 在左侧创建或切换工作空间。
2. 在中间区域创建分组，或从右侧保存当前窗口标签页。
3. 点击链接卡片可在新标签页打开网页。
4. 点击分组的“打开全部”可恢复该分组内保存的网页。
5. 按 `Ctrl/Command + K` 打开全局命令面板，搜索所有空间、分组、链接和当前窗口标签。
6. 使用右栏的“保存并关闭”或“保存并休眠”释放标签资源；固定标签和当前活动标签会被保留。
7. 在设置页中可以管理本机会话恢复点、导入导出、加密备份和配置远程同步。
8. 使用“新建空间”菜单中的“从浏览器书签导入”，选择书签目录导入当前空间。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取当前窗口标签页、切换标签页、打开新标签页 |
| `tabGroups` | 保存和恢复 Chrome 原生标签组的名称、颜色和折叠状态 |
| `bookmarks` | 仅在用户主动选择“从浏览器书签导入”时读取完整书签树以展示目录列表，并只导入用户最终选定的目录 |
| `storage` | 将空间、分组、链接和设置保存到本地浏览器 |
| `contextMenus` | 提供右键菜单快速保存入口 |
| `notifications` | 显示保存成功、失败和提示通知 |
| `activeTab` | 在当前活动标签页场景下辅助读取页面信息 |
| `favicon` | 使用浏览器内置 favicon 服务显示站点图标 |
| `alarms` | 每 15 分钟生成本机会话快照，并唤醒自动同步检查 |
| `https://*/*` | 访问 WebDAV 和 GitHub Gist 同步地址 |

项目不读取浏览历史或 Cookie。只有用户主动执行书签导入时才读取完整浏览器书签树用于目录选择，并只把最终选定目录导入工作台；项目不会把数据上传到自有服务器。

## 数据与隐私

所有工作台数据默认保存在 `chrome.storage.local` 中。完整原生备份会保留空间图标、布局、排序、更新时间和删除墓碑；TabTab 兼容导出只保留可见的空间、分组和链接。所有备份（包括加密备份）都会剔除 WebDAV 地址、账号、密码、GitHub Token 和同步加密密码，远程连接信息需要在新设备上重新填写。

会话安全网会在本机单独保存普通浏览器窗口中的 HTTP(S) URL、页面标题、固定/活动状态和原生标签组信息，最多保留 50 条、最长 30 天。会话快照不写入工作台数据，不参与工作台的 Gist/WebDAV 同步，也不包含在备份导出中。用户可以在会话恢复页面单独配置一个 WebDAV 地址来跨设备同步会话快照。

如果启用远程同步，远程地址、账号或访问令牌只应保存在本地浏览器扩展存储中，不应写入代码仓库或公开文档。

## 开发与测试

项目不依赖构建工具，可以直接作为浏览器扩展加载。

运行核心逻辑、浏览器消息、同步网络、传输和界面文案测试：

```powershell
npm.cmd test
```

运行真实 Chromium 扩展端到端测试：

```powershell
npm.cmd run test:e2e
```

端到端测试会构建 `dist/MyTabDesk-Chrome`，真实加载扩展，验证页面初始化、空间创建、Service Worker 消息保存、`chrome.storage.local` 持久化和刷新恢复。首次运行若本机没有 Chromium，请执行 `npx playwright install chromium`；也可通过 `MYTABDESK_CHROMIUM_EXECUTABLE` 指定浏览器路径。

运行全部质量门禁：

```powershell
npm.cmd run verify
```
