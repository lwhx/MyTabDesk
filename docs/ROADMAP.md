# MyTabDesk 功能路线图

> 定位：本地优先的自用标签页工作台，在 2-3 台电脑间通过 WebDAV/Gist 同步。
> 不追求轻量，追求功能齐全。

## 三、候选功能清单

### 第一梯队：多设备高频刚需

#### F1. 链接备注 / 标签
- 给链接加文字说明（如"注册流程在第3步"、"这个有API限流"）
- 多设备同步后备注比标题更能帮回忆
- **数据模型**：Link 增加 `note` 字段
- **UI**：卡片展开显示备注、编辑入口
- **同步**：随工作台数据自动同步

#### F2. 恢复到当前窗口
- 目前只创建新窗口；增加"恢复到当前窗口"选项
- 后台增加 `restoreTo: "current" | "new"` 参数
- `current` 时用 `chrome.tabs.create` 代替 `chrome.windows.create`
- **UI**：恢复按钮改为下拉菜单（恢复到新窗口 / 恢复到当前窗口）

#### F3. 批量选择恢复
- 从恢复点详情中勾选想要的标签，只恢复选中的
- 详情展开增加 checkbox，底部出现"恢复选中"按钮
- 对"17 个标签只想恢复 3 个"的场景非常有用

#### F4. 链接去重扫描
- 跨设备同步后可能产生重复链接
- 工具页面扫描全部空间，按 URL 聚合
- 展示重复组，一键保留最新/最早，删除其余
- 可按空间范围扫描

### 第二梯队：日常效率提升

#### F5. 恢复时跳过已打开的 URL
- 恢复分组或恢复点前，先 `chrome.tabs.query` 检查
- 已打开的 URL 自动跳过，避免重复
- **UI**：恢复时默认勾选"跳过已打开的页面"

#### F6. 从标签列表拖拽到分组
- 从右侧"当前标签"列表直接拖到中间的分组里
- 已有拖拽基础设施（链接排序、分组排序）
- 省去"保存→选分组→确认"三步操作

#### F7. 空间模板
- 创建新空间时选择模板
- 预设模板如：开发环境（GitHub/CI/文档）、设计参考、服务器管理
- 用户可自定义模板并保存

#### F8. 链接健康检查
- 批量检查 URL 是否仍可访问（HEAD 请求）
- 标记 404/超时的链接
- 可按空间/分组范围检查
- 提供"删除失效链接"按钮

### 第三梯队：进阶能力

#### F9. 回收站 / 撤销删除
- 删除空间/分组/链接后进入回收站
- 30 天内可恢复
- 删除后 Toast 提示"已删除，[撤销]"
- 当前墓碑机制已部分覆盖（同步层），但 UI 层无撤销

#### F10. 导出为 HTML
- 把分组导出为可分享的 HTML 页面
- 包含链接标题、URL 和备注
- 可用于离线分享或备份

#### F11. 定时自动保存指定窗口
- 比如每天 18:00 自动保存"工作"窗口到指定分组
- 比会话恢复更精确（用户指定）

#### F12. 标签颜色标记 / 优先级
- 给链接或分组加颜色标记
- 用于视觉区分重要/紧急/已处理等状态

### 第三点五梯队：跳出标签管理（用户确认）

#### F16. 使用统计仪表盘
- **每日/每周/每月保存和恢复趋势图**
  - 后台 Service Worker 记录每次保存/恢复操作的时间戳、空间名、链接数
  - 存储键 `mytabdesk_usage_stats`，按日期聚合
  - 前端独立页面展示折线图（用纯 CSS/SVG，不引入 Chart.js 等外部库）
- **按域名统计访问频率**
  - 从已保存链接中提取域名
  - 显示 Top 20 域名排行
  - 点击域名可筛选该域名下所有链接
- **按空间统计链接增长**
  - 每个空间的链接数、分组数、最后更新时间
  - 空间活跃度可视化（哪些空间经常用，哪些闲置）
- **标签页打开时长排行**
  - 后台 `chrome.tabs.onActivated` + `chrome.tabs.onRemoved` 追踪每个标签的活跃时长
  - 不记录 URL，只记录域名 + 时长（隐私安全）
  - 存储键 `mytabdesk_tab_time_stats`，按天聚合
  - 显示"今天最常停留的 10 个网站"
- **僵尸标签识别**
  - 打开很久但从未切换过去查看的标签
  - 标记为"可能不需要"，建议保存后关闭
- **空间健康度**
  - 最后更新时间
  - 链接存活率（结合 F8 链接健康检查）
  - 分组使用是否均衡

#### F17. 标签页生命周期管理
- **核心机制：标签页计时器**
  - `chrome.tabs.onCreated` → 开始计时
  - `chrome.tabs.onActivated` → 记录活跃时间戳
  - `chrome.tabs.onRemoved` → 停止计时，写入当日统计
  - 每个标签维护：创建时间、最后活跃时间、累计活跃时长
- **闲置规则引擎**
  - 规则 1：闲置超过 N 分钟未操作 → 标记为"僵尸标签"，右栏列表中显示警告图标
  - 规则 2：闲置超过 N 小时 → 自动保存到"暂存"分组并关闭（可配置）
  - 规则 3：超过 N 个标签同时打开 → 提示整理
  - 所有阈值用户可自定义
- **白名单机制**
  - 特定域名永不自动关闭（如 github.com、mail.google.com）
  - 固定标签永不自动关闭
  - 正在播放音频的标签永不自动关闭
  - 有未保存表单的标签弹窗确认
- **右栏增强**
  - 每个标签显示已打开时长（如"2h 15m"）
  - 闲置标签显示橙色警告图标
  - 长时间未看的标签显示红色建议关闭图标
  - 可按"打开时长"排序
- **一键整理**
  - "保存所有闲置标签并关闭"按钮
  - 自动将所有闲置超过阈值的标签保存到"暂存"分组
  - 然后批量关闭
  - 操作前弹窗确认，显示将处理的标签列表
- **数据存储**
  - 存储键 `mytabdesk_tab_lifecycle_config`：阈值和白名单配置
  - 存储键 `mytabdesk_tab_time_stats`：按天聚合的域名+时长数据
  - 不参与工作台数据同步（设备本地行为数据）
  - 不参与备份导出
- **设置页面**
  - 在设置页或独立的"标签管理"页面提供配置
  - 配置项：闲置阈值（分钟/小时）、最大标签数、白名单域名列表、是否自动关闭
  - 配置项：是否启用时长追踪
  - 配置项：统计数据保留天数（默认 90 天）

### 第四梯队：探索性

#### F13. 标签分组 AI 辅助
- 用 AI 根据页面标题和 URL 自动建议分组
- 用户确认后才执行
- 自用场景下价值有限（自己分类更准），但偶尔可帮忙整理

#### F14. 网站图标离线缓存
- 把 favicon 缓存到本地，离线也能显示
- 当前依赖 `favicon` 权限在线获取

#### F15. 数据统计仪表盘
- 显示每个空间的链接数、分组数
- 最近 30 天保存/恢复趋势
- 最常访问的域名

## 五、技术约束（实现时需遵守）

1. 不覆盖浏览器默认新标签页（不加 `chrome_url_overrides`）
2. 会话快照不进入工作台数据同步和备份导出
3. 所有凭据在备份时必须脱敏
4. 同步操作在 Web Locks / 串行链保护下执行
5. 新增权限最小化，manifest 中只加必需权限
6. 每项功能先写测试再实现
7. 真实 Chromium E2E 验证
8. 使用 textContent，不使用 innerHTML
